# 设计说明

这份文档解释“为什么这样组织”，不重复数据字段和构建命令。字段见 [DATA.md](DATA.md)，运行方式见 [MAINTAINER.md](MAINTAINER.md)。

## 1. 产品定位

电影年鉴是一个**静态的、可交叉浏览的电影数据库**，不是资讯站，也不是流媒体目录。

核心目标：

1. 用年份把电影放回时间线。
2. 用榜单给出一个可讨论的观看入口。
3. 用影片、导演、类型、国家把条目连起来。
4. 保持零后端：一份 JSON + 一个前端应用即可部署。

明确不做：

- 用户账号、评论、评分
- 实时票房、流媒体片源
- 个性化推荐
- 自动生成“有观点”的影评

精选、补看和点评是人工层，不由算法替代。

## 2. 信息架构

```text
首页
├─ 年份 → 年份页 → 影片
├─ 编辑精选 → 影片
├─ 类型 → 类型页 → 影片
├─ 国家 → 国家页 → 影片
├─ 导演 → 影人页 → 影片
├─ 影史前 10% → 影片
├─ 搜索 → 影片 / 影人 / 类型 / 国家
├─ 我的片单 → 影片
└─ 数据说明
```

路由表：

| 路由 | 页面 | 主要内容 |
| --- | --- | --- |
| `#/` | 首页 | 统计、精选、类型、国家、年份入口 |
| `#/year/:year` | 年份页 | 精选、补看、华语 20、Top 30、点评 |
| `#/film/:key` | 影片页 | 元数据、评分、简介、演职员、关联推荐 |
| `#/person/:name` | 影人页 | 导演作品、出演作品、平均分 |
| `#/genres` | 类型索引 | 全部类型及数量 |
| `#/genre/:id` | 类型页 | 该类型的综合高分 |
| `#/countries` | 国家索引 | 全部国家/地区及数量 |
| `#/country/:code` | 国家页 | 该国代表作、代表导演 |
| `#/all` | 影史榜 | 前 10%，年代筛选，60 部一页 |
| `#/search` | 搜索 | 关键词 + 年代 + 国家 + 类型 + 评分 |
| `#/people` | 影人索引 | 导演 / 演员切换 |
| `#/list` | 我的片单 | 看过、想看、评分、CSV |
| `#/about` | 数据说明 | 口径、来源、限制 |

路由使用 hash，原因是纯静态托管不需要服务端 rewrite；刷新任意页面都不会 404。

## 3. 页面设计

### 首页

首页承担“目录 + 气质”两件事：

- 顶部统计给出数据规模，先建立可信度。
- 编辑精选用 7 部片建立编辑口味，不做无限推荐流。
- 类型、国家、导演、年份是四个不同维度的入口。
- 年份按十年分组，避免 132 个年份一次性铺平。

### 年份页

年份页是产品的主轴，顺序固定：

```text
精选 → 补看 → 华语 Top 20 → IMDb Top 30 → 年度点评
```

精选是人工入口，榜单是数据入口；华语榜放在全球榜前面，符合中文用户的浏览优先级。Top 30 用紧凑排行榜而不是海报墙，避免页面过长。

### 影片页

影片页是“元数据卡 + 关系网”：

- 左侧海报，右侧评分、年份、国家、类型、片长、上映日期。
- 简介、导演、主演。
- “同系列 / 同导演 / 同类型 / 同国家”四组关联。
- 加入片单、豆瓣搜索、IMDb 链接。
- 精选短评只对人工精选影片显示。

关联推荐不是协同过滤，而是基于实体关系的规则推荐；这样可解释，也不需要后端。

### 索引页

导演、类型、国家、影史榜都遵循同一套卡片和排序逻辑，避免每个页面发明一种交互。

## 4. 实体模型

### 影片主键

| 主键 | 来源 | 说明 |
| --- | --- | --- |
| `tt...` | IMDb ID | Top 30、影史榜的主键 |
| `tmdb-...` | TMDB ID | 只在华语榜出现的影片 |
| `c-...` | 人工精选 | 没有匹配到榜单的精选 |
| `e-...` | 人工补看 | 没有匹配到榜单的补看 |

同一部影片在多个榜单出现时，通过 TMDB ID 对齐，尽量只保留一条记录。

### 合并顺序

`scripts/build-data.js` 按以下顺序构建：

1. **Top 30**：以 IMDb ID 建立基础记录，带上 IMDb 评分、票数、排名。
2. **华语榜**：用 TMDB ID 找到已有记录，补 `cnRank`；找不到则建 `tmdb-...` 记录。
3. **精选 / 补看**：根据 `curated-map.json` 和人工搜索缓存，挂到已有记录；仍找不到则建 `c-...` / `e-...`。
4. **TMDB 详情**：对核心影片覆盖简介、片长、类型、国家、公司、系列、导演、主演，并补 TMDB 评分。
5. **收尾**：用精选里的导演/国家做最后兜底，生成影人、类型、国家索引。

冲突原则：

- 中文片名优先：人工精选 → TMDB `zh-CN` → IMDb akas。
- 评分同时保留 IMDb 和 TMDB；页面默认显示 IMDb，缺失时回退 TMDB。
- 详情字段以 TMDB 为准；TMDB 没有的字段保留榜单基础值。
- 国家、片长、主演缺失时不造假，页面留空或显示占位。

### 影人

- 导演：出现在至少一部影片的导演字段，进入导演索引。
- 演员：至少两部作品才进入演员索引，避免把一次性群演做成空页面。
- 同一影人可同时是导演和演员；影人页分成“导演作品 / 出演”。

### 类型 / 国家 / 年份

这三类不是独立数据表，而是从影片字段反向聚合出来的索引：

- 类型：TMDB genre id → 中文名。
- 国家：TMDB ISO 3166-1 → 中文名，并补历史国家代码。
- 年份：优先上映年，其次从上映日期截取。

## 5. 数据流

```text
IMDb title.basics + title.ratings
        ↓ build-top30
    top30.json ─────────────┐
IMDb title.akas              │
        ↓ enrich-cn          │
    cn-titles.json           │
TMDB discover                │
        ↓ fetch-cn-films     │
    cn-films.json            │
TMDB /find                   │
        ↓ fetch-tmdb-find    │
    tmdb-find2.json          │
curated.json + curated-map   │
        ↓ match-curated      │
    curated-map.json         │
        ↓ fetch-tmdb-search  │
    curated-search.json      │
        ↓ build-core-ids     │
    core-ids.json            │
        ↓ fetch-tmdb-details │
    tmdb-details.json        │
        └──────────┬──────────┘
                   ↓ build-data
             data/films.json
                   ↓ build-site
          dist/index.html + offline.html
```

## 6. 排序与分页

### 年度 Top 30

- 只收电影和短片；1930 年后排除短片。
- 票数门槛按年代从 100 递增到 20,000。
- 用 IMDb 贝叶斯加权分排序，避免早期低票数影片虚高；同分看票数。

### 影史前 10%

- 从所有年度 Top 30 中筛出票数 ≥ 5 万的影片。
- 按评分排序，取约 10%（当前 396 部）。

### 综合分

搜索、类型、国家、相关推荐默认：

```text
score = rating × log10(votes + 10)
```

`+10` 是为了避免零票影片出现 `log10(0)`；用对数压缩票数，让高口碑但票数中等的影片不被大片完全淹没。

### 分页

影史榜和搜索结果每页 60 部。海报按需加载，避免一次渲染几百张图片。

## 7. 搜索与筛选

搜索不是全文搜索引擎，而是内存里的字段匹配：

- 片名、原名、年份
- 导演、演员
- 类型中文名
- 国家中文名
- 制片公司

筛选条件：

- 年代
- 国家/地区
- 类型
- 最低评分
- 只看华语

默认按综合分排序，也可以切到评分、年份、票数、片名。搜索页保留 URL 参数，筛选结果可分享、可刷新。

## 8. 静态与离线

线上版：

- 页面壳 + 内联 CSS/JS
- 运行时 `fetch('data/films.json')`
- 海报从 `image.tmdb.org` 加载，失败后切到 `wsrv.nl` 代理

离线版：

- 构建时把 JSON 直接内联进 HTML
- 去掉数据 `fetch`
- 海报不保证加载，失败显示首字占位
- 单文件可双击打开

## 9. 性能与降级

- 卡片海报用 `w200`，影片页用 `w342`。
- `loading="lazy"`。
- 影史榜、搜索结果限制 60 部。
- 图片失败显示首字色块，不显示破图。
- 没有简介、国家、片长时显示占位，不用假数据补齐。
- 所有外链使用 `target="_blank"` + `rel="noopener"`。

## 10. 设计取舍

- **不做后端**：换来零运维、可离线、GitHub Pages 免费托管；代价是不能有账号和实时数据。
- **不做自动影评**：精选和点评保留人工，算法只负责榜单和关联。
- **不追求全量电影**：以年度 Top 30、华语榜、人工精选为主，宁可少而可读，不做 IMDb 全库。
- **允许字段缺失**：Top 30 里有一部分冷门片没有 TMDB 详情；宁可留空，也不编造。
- **中文优先**：中文片名、华语榜、中文简介优先；没有中文名的影片保留原名。
